# Analytics Quick Start Guide

## 🎯 Overview
The analytics system provides professional, industrial-standard charts and visualizations for tracking investment performance.

---

## 🚀 Getting Started

### For Admins
1. **Access**: Navigate to `/admin/analytics` or click "Analytics" in the admin sidebar
2. **View**: System-wide metrics, revenue trends, user growth, and investment performance
3. **Features**: 7 professional charts + 4 KPI cards + 3 summary sections

### For Users
1. **Access**: Navigate to `/investment/analytics` or click "Analytics" in the investment menu
2. **View**: Personal portfolio performance, ROI, and investment progress
3. **Features**: 5 charts + active investment trackers + 4 KPI cards

---

## 📈 Key Metrics Explained

### ROI (Return on Investment)
```
ROI = ((Total Returns - Total Invested) / Total Invested) × 100%
```
Example: If you invested $1000 and received $1200 back, ROI = 20%

### Success Rate
```
Success Rate = (Completed Investments / Total Investments) × 100%
```
Example: 8 completed out of 10 total = 80% success rate

### Progress Percentage
Shows how much of the investment duration has elapsed
- 0% = Just started
- 50% = Halfway through
- 100% = Duration complete

### Expected Return
```
Expected Return = Investment Amount + Expected Profit
Expected Profit = (Amount × Plan Return Percentage) / 100
```

## 🐛 Troubleshooting

### Charts Not Loading
1. Check internet connection
2. Refresh the page
3. Clear browser cache
4. Try different browser

### No Data Showing
**For Admins**: Contact development team
**For Users**: 
- Ensure you have made investments
- Check if investments are in your account

### Incorrect Values
1. Refresh the page
2. Log out and log back in
3. Contact support if issue persists
